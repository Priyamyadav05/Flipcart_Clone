# Flipkart Clone

A simple Flipkart clone built using HTML and CSS. This project focuses on creating a visually similar layout to Flipkart, including the homepage, product sections, and navigation bar, with a clean and responsive design.

## 🚀 Features
- Responsive homepage layout
- Navigation bar similar to Flipkart
- Product categories and sections
- Clean and user-friendly UI

## 🛠️ Built With
- HTML5
- CSS3

## 📚 What I Learned
- Building structured layouts using HTML
- Styling and positioning using CSS
- Creating responsive web pages
- Improving frontend design skills
